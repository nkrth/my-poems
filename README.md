# My Daily Poems

![poem-count](https://img.shields.io/badge/poem--count-04-blue)

These are some rhymes I first cooked up from my phone, in memory of Dan Schiffman's [Git for Poets](https://youtube.com/playlist?list=PLRqwX-V7Uu6ZF9C0YMKuns9sLDzK6zoiV&si=S6HNb7Oe59p9bcJc) series. I remembered it's not just code that gets pushed on here.

The technology that first made this repo possible is a proprietary voice agent that told me the github commands in NATO spelling as I screenshared omalauncher terminal widget and editor application. 

In this last push, I used Github Desktop and VS Code to maintain a second day streak. Please find the humor in the similarity to other poems before raising any issues that I am unoriginal.
