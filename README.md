# My Daily Poems

![poem-count](https://img.shields.io/badge/poem--count-003-yellow)

These are some rhymes I cooked up from my phone, in memory of Dan Schiffman's Git for Poets series. I remembered it's not just code that gets pushed on here.

The technology that made this repo possible is a proprietary voice agent that spoonfed me the terminal commands in NATO spelling as I screenshared omalauncher terminal widget and editor application. 

It also helped me keep to keep meter and find wording.
